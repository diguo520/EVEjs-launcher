## 2. 契约（唯一事实来源）

`scripts/extract-contract.mjs` → `contract/ipc-channels.json` → `scripts/gen-contract.mjs` 产出三份：

| 产物 | 用途 |
| --- | --- |
| `src-tauri/src/ipc/channels.rs` | Rust 侧通道白名单（含 4 个单测） |
| `ui/src/api-shim.js` | **注入用纯 JS**（`initialization_script`，legacy 页面零改动；随源码进仓，再被拷进 `ui/dist`） |
| `ui/src/api-shim.generated.ts` | S6 React/Vite 侧使用（带类型） |
| `docs/ipc-contract.md` | 人读契约 |

实测计数：`invoke=76`、`send=6`（请求合计 **82**）、`events=7`、`window.api` 入口 **89**、
`ipc.ts` 注册 82；交叉校验「注册未暴露」为 0，动态注册点 0。

**修复的抽取缺陷（V1）**：原实现按 `signature.split(",")` 取参数名，
`patch: Record<string, string>` 会被切成两个参数，生成的 shim 出现
`[patch, string>]` 这种非法语法。现改为按 `<>{}[]()` 深度切分，并兼容
`limit = 100` 这类「只给默认值不给类型」的写法。

## 4. 与计划的偏差（都是有意的）

| # | 计划写法 | 实际做法 | 理由 |
| --- | --- | --- | --- |
| D1 | 注册 82 个 `#[tauri::command]` | 只注册 `launcher_invoke`，内部按 `channels.rs` 白名单二次校验 | 少 81 个注册点；契约变更不会漏改；未实现通道可统一回 `{ok:false}` |
| D2 | 引入 bundler 打 shim | `gen-contract.mjs` 直接产出纯 JS IIFE，配合 `withGlobalTauri: true` | 去掉 node_modules/锁文件/Vite 链路，`cargo build` 不依赖任何 JS 工具链；`include_str!` 的产物可被 `node --check` 独立校验 |
| D3 | `reqwest` 做 HTTP 探活 | 自研 `TcpStream` + `GET / HTTP/1.0` 解析状态码 | 只探本机 26001/26002，明文足够；省掉 hyper/TLS 一整棵依赖树（体积/内存目标优先）。S2 访问 GitHub HTTPS 时再引入体积可控的 `ureq` |
| D4 | 窗口几何写独立 `launcher-window.json` | 写 `launcher-settings.json` 的 `windowBounds`（与现役版 `saveWindowBounds` 同结构） | 单一事实来源，新旧版可互读；另外节流 400 ms 与现役版一致 |
| D5 | `tauri.conf.json` 里声明 `windows[]` | 删掉 `windows[]`，窗口只由 `lib.rs` 的 `WebviewWindowBuilder` 创建 | 两边同时声明会撞 label；而 `initialization_script` 只能在 builder 上设置 |
| D6 | `rust-toolchain.toml` 用 `1.98.1` | 用 `1.98.1-x86_64-pc-windows-msvc` | 裸版本号会触发 rustup 去 `static.rust-lang.org` 解析，本机该 URL 超时挂死（见 §6） |
| D7 | `stopWindow` 立即 `taskkill` | 先发 Ctrl+C，等 3s，再 `taskkill /T /F`；外部进程不接管 | 对齐现役版 `stopService` 的优雅退出语义 |

## 6. 已知问题（迁移期必须绕开）

1. **rustup 垫片联网解析会挂死**：`rust-toolchain.toml` 里写裸版本号时，rustup 会去拉
   `https://static.rust-lang.org/dist/channel-rust-<v>.toml`，本机该 URL 超时。
   已用具名 channel 规避；`scripts/build.ps1` 还会把工具链 bin 目录前置到 `PATH`。
2. **crates.io 稀疏索引时通时断**：单次 `cargo add` 可能 10 分钟以上。
   依赖版本改为「查稀疏索引后手写 `Cargo.toml`」，本次直接 `cargo fetch`（不用 `--locked`，因为已移除 `reqwest`）。
3. 首次编译 Tauri 依赖树耗时较长，属预期。
